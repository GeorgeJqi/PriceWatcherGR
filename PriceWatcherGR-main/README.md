# PriceWatcher GR 🇬🇷
### Ολοκληρωμένη Μηχανή Αναζήτησης & Σύγκρισης Μεταχειρισμένων Προϊόντων

Το **PriceWatcher GR** είναι μια σύγχρονη, πλήρης web εφαρμογή (Backend API & Responsive Frontend) για την ενοποιημένη αναζήτηση και σύγκριση μεταχειρισμένων και refurbished προϊόντων από κορυφαίες ελληνικές πλατφόρμες και καταστήματα.

## ⚖️ Υποστηριζόμενες Πλατφόρμες & Τεχνική/Νομική Αξιολόγηση

Σε απόλυτη συμμόρφωση με τις απαιτήσεις, ελέγχθηκε αναλυτικά για κάθε πλατφόρμα αν παρέχει επίσημο API, τι ορίζει το `robots.txt` και ποιοι είναι οι όροι χρήσης (ToS). **Δεν παρακάμπτονται CAPTCHA, έλεγχοι ταυτότητας ή άλλοι μηχανισμοί προστασίας.**

| Πλατφόρμα | Επίσημο Δημόσιο API | robots.txt | Τρόπος Συλλογής & Νομική Κατάσταση | Εναλλακτική Προσέγγιση |
| :--- | :---: | :---: | :--- | :--- |
| **Insomnia Classifieds** (`insomnia.gr`) | ❌ Όχι | `Disallow: /classifieds/search/` (για web crawlers προς αποφυγή crawl traps) | **Υποστηρίζεται Ήπια Συλλογή & Caching.** Τα αποτελέσματα είναι δημόσια προσβάσιμα χωρίς απαίτηση σύνδεσης. Γίνεται ήπια ανάκτηση με User-Agent, αυστηρό rate limiting και cache. | Άμεσος σύνδεσμος αναζήτησης με προ-συμπληρωμένο ερώτημα. |
| **Vendora** (`vendora.gr`) | ❌ Μόνο κλειστό Partner API | `Allow: /items/*/*.html$` <br> `Disallow: /api/`, `/partner-api/` | **Υποστηρίζεται μέσω Server-Side HTML.** Ανάκτηση των δημόσιων αποτελεσμάτων από τις σελίδες αναζήτησης (HTML) με σεβασμό στα όρια αιτημάτων και προσωρινή μνήμη. | Άμεσος σύνδεσμος αναζήτησης στο Vendora. |
| **ZER Shop** (`zer.gr`) | ❌ Όχι | `User-agent: * Allow: /` (Πλήρως επιτρεπτό) | **Πλήρως Υποστηριζόμενη Αυτόματη Συλλογή.** Δημόσιος κατάλογος μεταχειρισμένων/refurbished συσκευών με εγγύηση. Το `robots.txt` επιτρέπει απεριόριστη πρόσβαση. | Άμεσος σύνδεσμος ZER Shop. |
| **E-Byte** (`e-byte.gr`) | ❌ Όχι | `Allow: /` <br> `Disallow: /wp-admin/`, facet filters | **Πλήρως Υποστηριζόμενη Αυτόματη Συλλογή.** Εξειδικευμένο κατάστημα refurbished υπολογιστών. Η κεντρική αναζήτηση προϊόντων επιτρέπεται ρητά στο `robots.txt`. | Άμεσος σύνδεσμος E-Byte. |
| **PC Arena** (`pcarena.gr`) | ❌ Όχι | `Disallow: /*route=product/search` | **Υποστηρίζεται με Διακόπτη Ρύθμισης (.env).** OpenCart κατάστημα refurbished hardware. Το `robots.txt` περιλαμβάνει οδηγία αποφυγής ευρετηρίασης αναζητήσεων. Υποστηρίζεται συλλογή (ανενεργή/ενεργή μέσω `ENABLE_PCARENA`). | Άμεσος σύνδεσμος απευθείας αναζήτησης OpenCart. |
| **Facebook Marketplace** (`facebook.com`) | ❌ Μόνο Meta Commerce API για verified επιχειρήσεις | `Disallow: /` (Ρητή απαγόρευση automated bots) | 🚫 **ΑΥΤΟΜΑΤΟΠΟΙΗΜΕΝΟ SCRAPING ΜΗ ΕΠΙΤΡΕΠΤΟ.** Οι όροι της Meta (*Meta Automated Data Collection Terms*) και το `robots.txt` απαγορεύουν ρητά τη συλλογή χωρίς γραπτή άδεια. Απαιτείται login χρήστη και υπάρχουν CAPTCHA. | **1) Άμεσος Σύνδεσμος Αναζήτησης (1-Click Direct Redirection)** με προ-συμπληρωμένο το προϊόν.<br>**2) Φόρμα Χειροκίνητης Εισαγωγής Αγγελίας FB (Manual Import)** για παράλληλη σύγκριση τιμών. |

## ✨ Κύρια Χαρακτηριστικά

1. **Ενιαία Αναζήτηση & Παράλληλη Εκτέλεση:**
   - Ταυτόχρονη αναζήτηση με `ThreadPoolExecutor` σε όλες τις επιτρεπόμενες πηγές.
   - Εξαιρετική ταχύτητα (μέσος χρόνος απόκρισης ~1.2 δευτερόλεπτα).
   - Ανθεκτικότητα σε σφάλματα (error resilience): εάν κάποια πλατφόρμα καθυστερήσει ή αποτύχει, οι υπόλοιπες επιστρέφονται κανονικά.

2. **Κανονικοποίηση Τιμών σε Ευρώ (€):**
   - Αναγνώριση ελληνικών και ευρωπαϊκών αριθμητικών μορφών (`1.670 €`, `€ 1, 20`, `419.00 €`, `396,80 €`).
   - Ξεχωριστή επισήμανση αγγελιών χωρίς σαφή τιμή ("Ζήτηση", "Συζητήσιμη", 0€) με δυνατότητα απόκρυψης μέσω ειδικού φίλτρου.

3. **Προεπιλεγμένη Ταξινόμηση από τη Χαμηλότερη Τιμή:**
   - Τα αποτελέσματα ταξινομούνται αυτόματα από τη χαμηλότερη προς την υψηλότερη τιμή (`price_asc`).
   - Επισήμανση "Χαμηλότερη τιμή" στην πιο συμφέρουσα αγγελία.
   - Επιπλέον δυνατότητες ταξινόμησης: "Υψηλότερη τιμή πρώτα" και "Νεότερη ενημέρωση".

4. **Έξυπνα Φίλτρα:**
   - **Εύρος τιμών:** Ελάχιστη και μέγιστη τιμή σε Ευρώ (€).
   - **Πλατφόρμα:** Επιλογή συγκεκριμένης πηγής ή όλων.
   - **Τοποθεσία:** Φιλτράρισμα ανά πόλη (Αθήνα, Θεσσαλονίκη, Πάτρα, Ηράκλειο, Λάρισα, Πανελλαδικά / Αποστολή).
   - **Σαφής τιμή:** Διακόπτης εμφάνισης μόνο έγκυρων τιμών.

5. **Αφαίρεση Διπλοτύπων (Deduplication):**
   - Έλεγχος κανονικοποιημένων διευθύνσεων URL και ψηφιακής υπογραφής τίτλου/τιμής.

6. **Προσωρινή Μνήμη (In-Memory Cache):**
   - Caching αναζητήσεων για 300 δευτερόλεπτα (διαμορφώσιμο στο `.env`), εξασφαλίζοντας στιγμιαίες επαναλαμβανόμενες απαντήσεις (0.0s) και αποφυγή περιττής επιβάρυνσης των αρχικών ιστοσελίδων.

7. **Άμεσοι Σύνδεσμοι & Εισαγωγή Facebook Marketplace:**
   - Πλήκτρα 1-click Direct Search που ανοίγουν την ακριβή αναζήτηση στις πρωτογενείς πηγές.
   - Φόρμα χειροκίνητης εισαγωγής για αγγελίες του Facebook Marketplace, ώστε ο χρήστης να τις συγκρίνει δίπλα-δίπλα με τις υπόλοιπες.

8. **Σύγχρονο, Responsive UI:**
   - Σχεδιασμένο για κινητά, tablets και desktops με Tailwind CSS.
   - Επιλογή προβολής σε πλέγμα (Grid) ή λίστα (List).
   - Σαφείς επισημάνσεις (disclaimers) διαθεσιμότητας και επικαιροποίησης τιμών.

## 🚀 Οδηγίες Εγκατάστασης & Εκτέλεσης

### Προαπαιτούμενα
- Python 3.10 ή νεότερη (ελεγμένο και πλήρως συμβατό με Python 3.14).
- Σύνδεση στο διαδίκτυο για την ανάκτηση των αγγελιών.

### Βήμα 1: Κλωνοποίηση / Μετάβαση στον κατάλογο του έργου
```bash
cd /home/dark/pricewatcher
```

### Βήμα 2: Εγκατάσταση εξαρτήσεων
```bash
pip install -r requirements.txt
```

### Βήμα 3: Ρύθμιση αρχείου `.env`
Αντιγράψτε το πρότυπο ρυθμίσεων (εφόσον δεν υπάρχει ήδη):
```bash
cp .env.example .env
```

### Βήμα 4: Εκκίνηση του διακομιστή (Uvicorn)
```bash
python3 -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
ή απλά:
```bash
python3 -m app.main
```

### Βήμα 5: Άνοιγμα στον περιηγητή
Ανοίξτε στον browser τη διεύθυνση:
👉 **`http://localhost:8000/`** (ή την IP του μηχανήματός σας στο port `8000`).

## 📡 Τεκμηρίωση API Endpoints

### 1. `GET /api/search`
Κεντρική αναζήτηση προϊόντων.
- **Query Παράμετροι:**
  - `q` (string, υποχρεωτικό): Λέξη-κλειδί αναζήτησης (π.χ. `thinkpad`, `iphone 13`).
  - `min_price` (float, προαιρετικό): Ελάχιστη τιμή σε €.
  - `max_price` (float, προαιρετικό): Μέγιστη τιμή σε €.
  - `platform` (string, προαιρετικό): Φίλτρο πλατφόρμας (`all`, `insomnia`, `vendora`, `zer`, `ebyte`, `pcarena`, `facebook`).
  - `location` (string, προαιρετικό): Φίλτρο πόλης / τοποθεσίας (`all`, `Αθήνα`, `Θεσσαλονίκη` κλπ.).
  - `only_clear` (boolean, προαιρετικό): Εμφάνιση μόνο αγγελιών με έγκυρη σαφή τιμή (`true`/`false`).
  - `sort` (string, προαιρετικό): Τρόπος ταξινόμησης (`price_asc` [προεπιλογή], `price_desc`, `newest`).

**Παράδειγμα αιτήματος:**
```bash
curl "http://localhost:8000/api/search?q=thinkpad&min_price=200&max_price=600&sort=price_asc"
```

### 2. `GET /api/sources`
Επιστρέφει τη λίστα των υποστηριζόμενων πηγών, την κατάσταση λειτουργίας τους, τις νομικές σημειώσεις και τους κανόνες `robots.txt`.
```bash
curl "http://localhost:8000/api/sources"
```

### 3. `POST /api/manual`
Καταχώριση χειροκίνητης αγγελίας (π.χ. από Facebook Marketplace) για κοινή σύγκριση.
- **Request Body:**
```json
{
  "title": "Apple iPhone 13 128GB Midnight",
  "price": 450.00,
  "url": "https://www.facebook.com/marketplace/item/123456789/",
  "location": "Αθήνα, Μαρούσι",
  "description": "Σε άριστη κατάσταση με απόδειξη"
}
```

### 4. `GET /api/health`
Health check endpoint.
```bash
curl "http://localhost:8000/api/health"
```

## 🔒 Πολιτική Απορρήτου & Προστασία Προσωπικών Δεδομένων

- **Μηδενική αποθήκευση προσωπικών δεδομένων:** Η εφαρμογή δεν συλλέγει, δεν επεξεργάζεται και δεν αποθηκεύει προσωπικά στοιχεία πωλητών (ονόματα, τηλέφωνα, email, διευθύνσεις).
- **Περιορισμός δεδομένων:** Συλλέγονται μόνο τα απαραίτητα στοιχεία για την παρουσίαση του προϊόντος (τίτλος, τιμή, δημόσια περιγραφή/χαρακτηριστικά, πόλη καταστήματος/αποστολής, φωτογραφία και σύνδεσμος).
- **Ενημέρωση Χρηστών:** Οι τιμές και η διαθεσιμότητα αποτελούν ένδειξη της στιγμής της αναζήτησης. Η οριστική και έγκυρη πληροφόρηση ανήκει αποκλειστικά στην ιστοσελίδα της αρχικής αγγελίας.
